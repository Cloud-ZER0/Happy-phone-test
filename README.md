## Happy Phone Test

Тестовое приложение на **Next.js (App Router)** + **React** + **TypeScript** + **Tailwind CSS**.

### Что умеет

- **Создание заказа**: многошаговая форма на главной странице.
- **Список заказов**: `/orders`
- **Детальная страница заказа**: `/orders/[id]`

### Где хранятся данные

- Заказы и прогресс формы сохраняются в **`localStorage`** в браузере.
- Чтение из `localStorage` защищено: используется безопасный `JSON.parse` + **Zod-валидация**. Если данные в storage повреждены/устарели, приложение не падает и использует безопасные значения по умолчанию.

### Структура проекта (кратко)

- `src/app/*` — роуты Next.js (ре-экспорт страниц из модулей)
- `src/modules/*` — фичи (form/order/shared/api)
- `src/modules/api/*` — работа с `localStorage`

### Быстрый старт

Установить зависимости и запустить dev-сервер:

```bash
npm ci
npm run dev
```

Открыть `http://localhost:3000`.
